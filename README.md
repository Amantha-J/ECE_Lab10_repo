## Lab Questions

### What is difference between edge and level sensitive circuits?
Edge sensitive circuits store the input right as the enable signal goes from off to on, like a snapshot.
Meanwhile, level sensitive circuits store input for the entire duration the enable signal is on. 
One is a photo and the other is a video.

### Why is it important to declare initial state?
It's important to declare initial states because otherwise it's unknown and waterfall into hell.
Also helps to have a consistent start state.

### What do edge sensitive circuits let us build?
Anything build off of clock cycles, like counters.
